Ask-Claude settings

Stored only in this browser's localStorage, on this device. Requests go straight from your browser to Anthropic's API using this key — anyone with access to this browser profile can read it back out of localStorage or from network requests, so don't use this on a shared or public computer. Get a key at console.anthropic.com. If Ask-Claude requests fail immediately, serve this file over http://localhost instead of opening it directly (file://) — some browsers block cross-origin requests from local files.
